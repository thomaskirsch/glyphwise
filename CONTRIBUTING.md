# Contributing

Thank you for helping! Especially welcome:

- **Native speakers and teachers** who can review stroke order and direction.
  Open an issue per character (“Hebrew ל: stroke 1 should start at …”).
  Once a character is confirmed, its `verified` flag is set to `true`.
- Stroke data for new scripts, memory aids, example words, translations of the UI.
- Bug reports from real devices (phone model, finger or stylus).

## Ground rules

1. **Only material you may share under our licenses.** Code: MPL-2.0.
   Content: CC BY-SA 4.0. Do not copy from textbooks, apps or fonts.
   Data under a *non-commercial* license (e.g. CC BY-NC) cannot be used.
2. **No personal data** – no names, e-mail addresses, voices or photos of
   people in the repository. Use your GitHub noreply address for commits.
3. Run `npm test` and `npm run check:data` before opening a pull request.

## Developer Certificate of Origin (DCO)

By adding a `Signed-off-by` line to your commits you confirm that you wrote
the contribution or otherwise have the right to submit it under the
project's licenses ([developercertificate.org](https://developercertificate.org/)).

```bash
git commit -s -m "Add Hebrew letter gimel"
```
